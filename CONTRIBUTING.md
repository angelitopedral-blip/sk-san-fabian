# Contributing / Paano mag-ambag

This is a free, open-source public-information project about the SK budgets of San Fabian, Pangasinan. Contributions are welcome.

## Report a correction (Mag-report ng mali)
Open an Issue with: the barangay, the slide or number, and what the original document says (a photo or scan helps). Numbers come from scanned documents and may be misread.

## Add data for a barangay
Send the scanned SK Annual Budget FY 2026, ABYIP and CBYDP. Rules we follow: show names and positions only (no signatures or stamps on slides), neutral wording, no accusations, and always tell readers to compare with the original.

## Improve the site
The site is plain static HTML/CSS/JS. Pull requests that improve accessibility, speed, translations (Filipino/English/Ilocano/Pangasinan) or the data pages are welcome.
